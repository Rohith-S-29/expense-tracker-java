# Expense Tracker - Java Project

A console-based Expense Tracker application built using Java.

## Features

- Add, view, edit, and delete expenses
- Search expenses by description or category
- Filter expenses by category
- Category-wise expense analysis
- Monthly expense report with average spending
- Monthly budget tracking and over-budget alerts
- Export expenses to a timestamped CSV report
- Automatic data persistence using CSV files
- Input validation for dates, amounts, and IDs

## Technologies Used

- Java
- Object-Oriented Programming
- File Handling
- CSV Storage
- VS Code

## How to Run

```bash
javac src/*.java
java -cp src Main
```
